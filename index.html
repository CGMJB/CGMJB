系统信息

GitHub Pages 托管版说明

本系统使用 GitHub Pages 托管静态前端页面，专为 GitHub 托管环境优化。

系统架构：

前端

静态HTML/CSS/JS页面托管在GitHub Pages上

后端

使用独立API服务处理数据请求

数据

模拟数据存储在API服务中

GitHub Pages 优势：

  • 免费静态网站托管
  • 全球CDN加速
  • 与Git仓库无缝集成
  • 自动SSL证书
  • 支持自定义域名

GitHub Pages 功能

GitHub Pages 直接从GitHub仓库托管静态网站文件，支持Jekyll主题，并可通过GitHub Actions实现自动化部署。

部署说明： 此版本已完全适配GitHub Pages部署，只需将代码推送到GitHub仓库的gh-pages分支或docs文件夹即可。

GitHub Pages会自动构建并发布您的网站。
